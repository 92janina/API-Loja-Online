# 🛒 API Loja Online

Projeto acadêmico desenvolvido durante a disciplina **Desenvolvimento de Serviços e APIs** do curso de **Análise e Desenvolvimento de Sistemas da UniSenac**.

O projeto consiste em uma API REST para gerenciamento de uma loja online, desenvolvida com **Node.js**, **Express.js** e **MySQL**, aplicando conceitos de desenvolvimento backend e integração com banco de dados.

---

# 🎯 Objetivo

Desenvolver uma API REST capaz de realizar operações de cadastro, consulta, atualização e exclusão de dados, utilizando boas práticas de desenvolvimento e integração com banco de dados relacionais.

```bash

```
